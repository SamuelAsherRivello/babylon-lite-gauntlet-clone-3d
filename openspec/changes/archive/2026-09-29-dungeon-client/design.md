# Design

## Context
Explore: template Vite app root and corner roles retained. Babylon Lite WebGPU only with useful unsupported recovery; released exact shared client. Steep topdown tracking camera and portrait game area. Four persistent class buttons and uniquely colored numbered rings plus party UI. Keyboard WASD/arrows, hold Space attack, E magic; touch joystick and attack/magic. Local settings pause only input. Responsive HUD, reconnect/full/retry, victory/defeat replay. Public Pages build asset paths, version and README original prompt.

## Goals / Non-Goals
Goals: fulfill the supplied game brief and verify behavior. Non-goals: accounts, persistent saves, multiple levels.
